# Vokto v1.0.0 — Premium Voice Typing

## 🎙️ First Stable Release

Press Alt+Q anywhere, talk naturally, text streams live into any app.

---

## ✨ What's New

### Core Features

- **Global hotkey (Alt+Q)** — toggle recording from anywhere, no app focus needed
- **Live streaming transcription** — text appears as you speak, phrase by phrase
- **Adaptive VAD** — detects natural pauses (~1.5s) and ships each clause instantly
- **Auto-paste** — text is pasted directly where your cursor is (no copy-paste needed)

### Premium Features

- **Multi-key rotation** — add multiple Groq keys, Vokto picks the least-loaded one
- **Latency timer** — shows transcription speed in the pill (clean, subtle)
- **Whisper prompt chaining** — keeps punctuation and tone continuous across chunks
- **Hallucination guard** — drops Whisper caption loops and junk text automatically
- **Never lose a recording** — chunks are temp-saved before upload; retries on failure
- **Native paste module** — no console flash, clean and silent ✅
- **Custom hotkey fixes** — fully working, set any combo you want ✅

### Privacy & Security

- **DPAPI-encrypted keys** — stored only on your machine (Windows protected)
- **No telemetry** — absolutely zero data collection
- **No accounts** — no sign-up, no cloud storage
- **Only outbound traffic** — just the Groq API calls you configure

### Dashboard

- **Transcription history** — browse all your past recordings
- **Copy entries** — copy individual or export all as .txt
- **Usage stats** — see today's requests and remaining quota

### Settings

- **Custom hotkey** — pick a preset or press any combo to set your own
- **Add multiple Groq keys** — rotate between them automatically
- **Key health** — see status (ready / rate-limited / error) for each key
- **Auto-paste toggle** — turn on/off

---

## 🐛 Known Quirks

- **Silence timeout** — Vokto auto-closes after 2 minutes of silence; this is intentional to prevent background noise transcription
- **Icon resolution** — minor pixelation on some displays; will be improved in v1.1.0
